Información sobre privacidad y seguimiento

Este sitio utiliza Cloudflare Pages y una base de datos Cloudflare D1 para registrar accesos.

Qué se registra

  • Fecha y hora de entrada y, cuando el navegador lo comunica, salida aproximada.
  • Sitio y ruta solicitada.
  • Si aceptas el seguimiento: un identificador aleatorio del navegador, navegador, sistema operativo, tipo de dispositivo, idioma, zona horaria, tamaño de pantalla y ubicación aproximada facilitada por la conexión.
  • La IP original no se guarda. Si aceptas, se puede guardar un HMAC de la IP para distinguir conexiones; no es una anonimización irreversible.

Identificación

El identificador reconoce ese navegador mientras conserve la cookie. No revela por sí solo el nombre de la persona. Borrar cookies, cambiar de navegador o usar otro dispositivo puede generar un identificador distinto.

Cookies

Se usa una cookie técnica de sesión para permitir que el navegador cargue los archivos del sitio protegido mientras decides. Es temporal y no se utiliza para reconocerte entre visitas. El panel también utiliza una cookie de sesión para mantener abierta la sesión de administración.

Consentimiento

Si aceptas, se guardará una cookie propia para recordar el consentimiento y reconocer el navegador durante un máximo de un año. La preferencia se conserva hasta seis meses. Si rechazas, las visitas se registran de forma anónima, sin asociarlas a un dispositivo reconocido.

Responsable del sitio: el administrador de esta instalación debe completar aquí su identidad, un correo de contacto, la finalidad concreta, la base jurídica, el plazo de conservación y el procedimiento para ejercer los derechos de protección de datos antes de publicarla.

Cambiar la decisión

Puedes retirar el consentimiento en este navegador. Las visitas futuras dejarán de asociarse al identificador anterior.
